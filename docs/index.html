01

수명 분포

배치마다 수명 범위가 얼마나 다른가요?

Batch 1의 최단 수명은 534사이클이고 Batch 2의 43셀 중 33셀은 500사이클 미만입니다. 짧은 수명 구간은 학습 범위 밖입니다.

02

초기 신호와 수명

X축 변수를 바꿔 관계를 비교할 수 있습니다.

ΔQ(V) 변화가 큰 셀은 세 배치 모두 짧은 수명 방향이지만, 신호의 절대 수준은 배치마다 이동합니다.

03

실제 수명 · 예측 수명

점선에 가까울수록 오차가 작습니다.

Batch 1은 최종 모델의 학습 배치이므로 이 차트에 학습 셀 예측을 섞지 않았습니다. Batch 2·3의 사후 평가 결과만 표시합니다.

04

예측 오차의 방향

0 위는 수명을 길게, 아래는 짧게 예측했습니다.

전체 MAPE와 함께 짧은 수명의 과대예측을 봅니다. 실제 운영에서 점검을 늦추는 방향의 오차이기 때문입니다.
